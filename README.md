Домашние задания для раздела ООП

1. В папке src 
Созданы классы Product и Category
Для этих двух классов добавлена инициализацию так, 
чтобы каждый параметр был передан при создании объекта и сохранен.
Также для класса Category добавлено два атрибута класса,
(количество категорий и количество товаров).
Доступ к этим атрибутам должен быть у каждого объекта класса, 
и в них должна храниться общая информация для всех объектов.
Созданы два класса наследников класса Product: «Смартфон» (Smartphone) и «Трава газонная» (LawnGrass) 
Класс «Смартфон» расширен атрибутами: производительность, модель, объем встроенной памяти, цвет 
Класс «Трава газонная» расширен атрибутами: страна-производитель, срок прорастания, цвет 
Доработана функциональность сложения для одинаковых классов продуктов 
Ошибка TypeError при сложении разных классов продуктов 
Метод добавления продукта в категорию защищен от добавления объектов не класса Product или его наследников 

2. В папке test 
Созданы основные тесты к инициализации классов

проект использует виртульное окружение poetry,
конфигурация в pyproject.toml
